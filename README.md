# Multiline Text

Ever tried to put a second line in a text object and found out the editor just won't let you? This mod fixes that.

Open a text object in the editor and type `\n` wherever you want the line to break. When you confirm, it turns into a real new line.

**Example:** `Hi\nWorld` shows up as

```
Hi
World
```

## Settings

- **Newline Token:** the text that gets turned into a line break. It's `\n` by default, but you can change it to anything you like, including symbols (for example `|` or `//`).

## Notes

- Works on Windows, Mac and Android.
- If you change the token, use something you won't need to type in normal text.
